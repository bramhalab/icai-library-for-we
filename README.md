# ICAI Study Library

A simple, login-free website to read ICAI study material folder by folder, from any phone or laptop.

**Live site:** https://bramhalab.github.io/icai-library-for-we/
**Files are stored here:** https://huggingface.co/datasets/Brand1809/ICAI_SM_CFA

## Why I built this

While studying, my phone storage was full, and I could not keep all the PDFs on it. The official ICAI websites need an OTP or password every time, which is slow when you just want to open one MTP or RTP and practice.

So I put the material in one place where any file is a few taps away, with no sign-in.

## What it does

- Browse by folder: MTP, RTP, subject, year, month
- Search across all files (for example `MTP AUG 25 law`)
- Read PDFs inside the page or open them in a new tab
- "Continue reading" shows your last five files
- Soft sound effects, with a mute button
- Works on mobile, with dark mode
